# game-body

固定的 **Slay the Spire 2 0.107.1** 游戏快照，供 pinned CI 与需要仓库内依赖的验证使用。

## 本地验证

本机已有匹配的游戏安装时，编译和离线原生合同可以直接读取安装目录的 DLL，无需另复制 EXE/PCK，也不需要启动游戏。使用 [离线验证入口](../source/tools/README.md#不启动游戏的完整验证) 指定 `-GameDir`。

本目录的二进制通过 Git LFS 管理；README 是普通文本。开发工作目录未物化这些二进制时，外部安装验证仍可运行；Git 跟踪状态和 CI 所需的 LFS 输入仍需保留。仓库 hygiene 检查只证明文件组织与文档引用，不证明 LFS 内容已下载或游戏能够启动。

## 保留边界

- 这是 CI 的固定输入，不属于可随意删除的生成文件。
- 不保存运行日志、存档、用户配置、问题包或临时 Mod 输出。
- 除非明确切换目标版本，否则不要替换 DLL/EXE/PCK。
- 生产源码在 `source/`；本地游戏安装目录不参与仓库清理。
