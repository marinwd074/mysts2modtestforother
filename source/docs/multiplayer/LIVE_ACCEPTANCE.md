# 多人连续行动改动的实机验收

状态为待验。当前证据来自 pinned 0.107.1 离线原生模型。现场操作流程见 [RUNBOOK](RUNBOOK.md)，已有问题包与个别复验要求见 [当前交接](../CODEX_HANDOFF.md#当前未验证边界)。

| 场景 | 接纳条件 |
|---|---|
| 同回合内队友连出多张牌，其中一张击杀旧目标 | 立即停止过期执行。同一建议等待刷新时合并状态戳检查，稳定后以最新根重放或重搜。记录同一段动作中实际作废的展开、转移与取消排空。 |
| 连续多个回合引发路线失效，随后一个完整安静回合 | 自动请求跳过可选的额外深入和前缀补搜。合格完整重放仍可接纳。安静回合后可选工作恢复，手动计算按原策略运行。 |
| 共享生成或选牌 RNG 改变，本地目标和手牌暂时相同 | 旧选项与旧授权被拒绝。新根重新捕获并审查实际原生选项。包括 Headbutt 和回合开始选牌。 |
| 显式采用期间发生连续队友动作或 RNG 失效 | 保留采用意图。每次恢复均校验新根、评价窗口及动作身份。最终仅新授权可以提交本地动作。 |
| 围攻与夹击进入实验建议 | 原生效果、归属及同回合命中历史匹配；仅建议路线在任何自动动作提交前被拒绝。 |
| 性能与峰值内存 | 同构建、同预算下记录请求到首条已审核路线的墙钟、取消排空、线程累计分配、进程峰值工作集与私有内存、最大帧间隔。保留单人完整战斗对照和队友动作顺序。 |

记录每条结果的构建、Host/Client 角色、场景、预算和首个失败原因。离线分配降幅单列，实机延迟和内存峰值使用现场采样。
