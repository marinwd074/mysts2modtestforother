# 多人连续行动改动的实机验收

已完成同机 ENet 的深度对照、单人完整预测抽查、首战帧间隔复测及高血场景的目标击杀修复。生产多人继续默认三回合。原始结果及部分通过的用例见 [2026-11-07 实机对照](LIVE_ACCEPTANCE_2026-11-07.md)。现场操作流程见 [RUNBOOK](RUNBOOK.md)，已有问题包与个别复验要求见 [当前交接](../CODEX_HANDOFF.md#当前未验证边界)。

| 场景 | 接纳条件 | 当前证据 |
|---|---|---|
| 同回合内队友连出多张牌，其中一张击杀旧目标 | 停止过期执行。同一建议等待刷新时合并状态戳检查，稳定后以最新根重放或重搜。记录实际作废的展开、转移与取消排空。 | 高血击杀后自动重搜通过。同一稳定窗口内合并、旧授权正在执行时的停止和两种深度的取消对照待验。 |
| 连续多个回合引发路线失效，随后一个完整安静回合 | 自动请求跳过可选深入和前缀补搜，合格重放仍可接纳。安静回合后恢复可选工作，手动计算按原策略运行。 | 离线合同通过。实机的两次击杀相隔一个回合，未构成连续失效。 |
| 共享生成或选牌 RNG 改变，本地目标和手牌暂时相同 | 旧选项与旧授权被拒绝。新根重新捕获并审查实际原生选项。包括 Headbutt 和回合开始选牌。 | 发现改变生成 RNG 后，新根重算及部署通过。Headbutt 自动选牌通过。回合开始选择已显示可见界面，自动接管待验。 |
| 显式采用期间发生连续队友动作或 RNG 失效 | 保留采用意图。每次恢复均校验新根、评价窗口及动作身份。最终仅新授权可以提交本地动作。 | 离线重放通过，连续实机失效仍待验。 |
| 围攻与夹击进入实验建议 | 原生效果、归属及同回合命中历史匹配；仅建议路线在任何自动动作提交前被拒绝。 | 两张牌的效果和归属通过，含围攻的存活路线无法自动执行。夹击的自动部署边界仍为离线证据。 |
| 性能与峰值内存 | 记录首条审核路线的墙钟、取消排空、线程累计分配、进程峰值内存、最大帧间隔。保留相同预算和队友动作顺序。 | 已留档同机深度对照、首战帧间隔与设置页首次打开耗时。新版剩余长帧主要位于浮窗挂载。 |

记录每条结果的构建、Host/Client 角色、场景、预算和首个失败原因。离线分配降幅单列，实机延迟和内存峰值使用现场采样。

## 下一轮实机前的离线收尾

- 旧实机日志中，从根捕获结束到 `UI_POSITION_LOADED`，六回合 Client 用时 1,917 ms，单人用时 1,948 ms；两次根捕获本身约 51 ms。这个区间包含浮窗构建及其他主线程准备。已将隐藏设置页改为首次打开时创建。主题重建若原来打开设置，则恢复设置页。首次打开设置的耗时单列。
- 下次冷启动记录 `SEARCH_REQUEST_TIMELINE` 的 `SearchingOverlayStarted` 与 `SearchingOverlayFinished`，再用 `UI_COLD_CREATE` 分离同步构建、挂载和初始布局，用 `UI_SETTINGS_CREATE` 记录首次打开设置。请求时间线与冷启动拆分事件会保留在有大小上限的进程日志，详细战斗日志轮换后仍可检查。待刷新候选若在稳定根拒绝，记录首个不兼容字段或候选缺失类别。
- 同一三敌离线夹具分别跑默认三回合和自适应上限六回合。两组均在第 5 回合获胜、本地战损 0，均拒绝 5 个旧版本，覆盖一次旧目标死亡和一次更新合并。相同进度点取消的两个 worker 都退出，并记录 1 次展开和 8 次模拟转移。安静回合恢复及旧授权拒绝由交错合同核对。
- 共享 RNG 的 10 个定向用例和连续失效后的显式采用重放通过。围攻、夹击的预测与原生效果一致，两张牌的 `AdviceOnly` 动作都被实际部署切片入口拦下。上述结果均来自离线工具，原生联机选牌界面、正式部署和冷启动优化后的帧间隔仍由表中实机用例验收。
