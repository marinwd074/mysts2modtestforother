# 在线统计客户端说明

本仓库保留 CombatSolver 客户端的在线统计协议实现，但不再包含统计服务端、管理后台、部署脚本或后台源码。

## 客户端行为

在线统计默认开启，可在设置中的“在线统计”区域关闭。启用时，客户端按既有协议定期发送在线状态和跑局统计；关闭后停止后续上报。完整路线、卡组、存档、Steam ID 与聊天内容不属于在线状态心跳字段。

客户端只在构建产物中存在有效的 `PresenceEndpoint` 与 `PresenceCertificateSha256` 元数据时建立统计连接；普通源码构建若没有这些外部配置，不会启动在线统计网络请求。

无头求解子进程、无人测试进程和多人跑局保持不上传。相关客户端实现位于 `src/Diagnostics/Telemetry/OnlinePresence.cs`、`RunStatistics.cs` 与 `RunStatisticsStore.cs`。

## 仓库公开边界

本仓库不包含在线统计服务端源码、管理后台、监控工作台、服务部署文件或私有运维说明。实际服务地址、证书指纹、凭据和部署配置均不应提交到本仓库。
