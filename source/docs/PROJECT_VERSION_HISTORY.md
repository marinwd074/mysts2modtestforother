# 项目版本更新历史

本文件记录 CombatSolver fork 的功能里程碑；原 v0.01–v0.23 重新按功能归并，自 **1.01** 起编号。小更新 **+0.01**，大型功能或架构更新 **+0.10**，固定保留两位小数。每版对应一个功能提交和 `project-vX.XX` 标签，最新版本见 [`../PROJECT_VERSION`](../PROJECT_VERSION)。

这是开发历史的追溯编号。上游 Mod 基线仍为 **0.40.2**，游戏 / RitsuLib 仍为 **0.107.1**；项目里程碑标签不触发打包发布。条目描述该版引入的变化；当前能力和未完成项以 [`CODEX_HANDOFF.md`](CODEX_HANDOFF.md) 为准，团队预测实验也不因此变成默认能力。

同一功能的实现、修补、相关验证与文档收尾归入同版；独立功能保留独立提交。维护方法见 [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md)，原细粒度历史保留在 `archive/main-before-versioning-20261002-0a104a1`，标签注释记录对应原始范围。
